# 課題名
スキルチェックシート＆面接ヒアリング支援ツール

## 課題内容（どんな作品か）
- 求職者に対する「スキル・マインド診断」の実施から、面接官による「深掘りヒアリング（音声録音付き）」、そして総合管理者による「AI分析用データの抽出（ZIPダウンロード）」までを一気通貫で行うHR Techアプリケーションです。
フロントエンドはSPA（Single Page Application）風のUIで直感的に操作でき、バックエンドはPHPとMySQLを用いて堅牢にデータを管理しています。

## 工夫した点・こだわった点
- UI/UXの向上（SPA風設計）：画面全体をリロードせずに、JavaScriptを用いて動的に画面を切り替えることで、ユーザーの体感待ち時間を減らしました。
- 関心の分離とデータ管理：設問データは外部のJSONファイルで管理し、システムロジックから切り離しました。
- データベースは正規化のルールに従い、候補者情報と回答データを別のテーブルに分けて管理しています。
- 非同期通信による大容量データ処理：面接時の録音データ（Blob）や回答データを、fetch や $.ajax を用いて非同期でサーバー（PHP）へ送信する仕組みを構築しました。  

## 難しかった点・次回トライしたいこと（又は機能）
- 難しかった点：SPA風にHTMLの構造を書き換えた際、JavaScriptが要素を見失う「DOMの迷子」や、jQueryの初期化処理が重複するトラブルが発生しました。また、OS環境（Mac）におけるシステム一時フォルダの権限エラーなど、環境依存のトラブルシューティングに苦労しました。次回トライしたいこと：ダウンロードしたZIPデータ（テキストと音声）を、直接生成AIのAPI（GeminiやChatGPT）へ送信し、ダッシュボード上で自動総評を出力する機能。JOIN や GROUP BY を活用し、管理者ダッシュボードに「全体スコアの平均値」や「質問ごとの傾向」を示す統計グラフ機能を追加すること。
